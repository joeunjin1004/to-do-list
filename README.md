# 📝 Simple To-Do List Web App

깔끔하고 직관적인 웹 기반 To-Do List 애플리케이션입니다.

- 🔗 **배포 링크**: [https://todo-list-alpha-wheat.vercel.app](https://todo-list-alpha-wheat.vercel.app)

---

## ✨ 주요 기능
- **할 일 관리**: 추가, 수정(더블 클릭 또는 수정 버튼), 삭제, 완료 체크
- **실시간 검색**: 상단 검색창에서 키워드로 할 일 즉시 필터링
- **드래그 앤 드롭(Drag & Drop)**: 마우스로 할 일 항목을 끌어서 자유롭게 순서 재정렬
- **로컬 스토리지(LocalStorage) 연동**: 브라우저를 새로고침하거나 종료해도 데이터 및 순서 자동 보존
- **상태별 필터링**: 전체 / 진행 중 / 완료 항목별 필터 제공
- **완료 항목 일괄 삭제**: 완료된 항목을 한 번에 정리하는 편의 기능
- **다크 모드(Dark Mode) 지원**: 라이트/다크 테마 전환 및 사용자 설정 저장
- **등록 시각 기록**: 할 일을 등록한 일시 자동 표시
- **반응형 디자인**: 모바일 및 데스크톱 환경 모두 최적화
